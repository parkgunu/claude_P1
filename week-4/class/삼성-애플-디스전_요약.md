## 한 줄 요약

삼성전자가 애플의 첫 폴더블폰 '아이폰 듀오' 공개를 계기로, **뉴질랜드·미국 법인이 동시에 SNS 말장난 마케팅을 펼치며 애플을 공개 조롱**하고 갤럭시로의 기기 변경을 유도하고 있다.

---

## 핵심 3가지

1. **'팀 쿡' 동명이인 낚시** — 삼성 뉴질랜드 법인이 애플 CEO와 동명인 일반인을 내세워 "팀이 갤럭시로 갈아탔다"고 발표한 뒤 "어떤 팀 쿡을 생각하셨나요?"로 반전을 주는 광고를 공개.
2. **"우리가 먼저 접었다"** — 삼성 미국 법인은 애플이 폴더블 기술을 뒤늦게 따라왔다는 메시지를 X에 반복 게시. 일부 글은 조회수 **1,000만 회 이상**.
3. **조롱 범위가 제품명·액세서리까지 확대** — '듀오' 제품명은 듀오링고를 태그해 작명까지 베꼈다고 비꼬고, 아이폰 액세서리는 "음식은 없고 소스만 있는 느낌"이라 비판.

## 주체별 정리

### 삼성전자 뉴질랜드 법인 (9월 11일, 공식 인스타그램)

| 구분 | 내용 |
|---|---|
| 형식 | 동명이인을 활용한 말장난(pun) 광고 이미지 |
| 등장인물 | 애플 CEO 팀 쿡과 **이름이 같은 일반인** '팀' (뉴질랜드 파머스턴노스 거주) |
| 소품 | 갤럭시 Z 폴드를 든 모습 |
| 카피 ① | "대형 소식입니다. 팀이 갤럭시 폰으로 갈아탔습니다" |
| 카피 ② | "맞습니다. 바로 그 팀 쿡입니다 — 파머스턴노스의 팀이죠" |
| 마무리 | **"어떤 팀 쿡을 생각하셨나요?"** |
| 의도 | 쿡 CEO가 아이폰을 버리고 갤럭시를 택한 것처럼 오인하게 유도 |

### 삼성전자 미국 모바일 법인 (공식 X 계정)

| 구분 | 내용 |
|---|---|
| 시점 | 애플 폴더블폰 **'아이폰 듀오'** 공개 전후 |
| 멘트 ① | "우리는 여기서 제대로 접고 있을게요" |
| 멘트 ② | "그 재탕 다 끝나면 알려 달라" |
| 멘트 ③ | '듀오' 이름을 두고 **듀오링고 계정 태그** → "그들이 우리 것도 베꼈다" |
| 멘트 ④ | 아이폰 액세서리 → "음식은 없고 소스만 있는 느낌" |
| 성과 | 일부 게시물 수백만 ~ **1,000만 회 이상** 조회 |
| 행동 유도 | **"이제 갈아탈 때"** 해시태그로 갤럭시 전환 직접 권유 |

## 흐름

```
애플, 첫 폴더블폰 '아이폰 듀오' 공개
            │
            ├─ 삼성 미국 법인 (X)  ──→  "폴더블은 우리가 원조" 기술 선점 주장
            │                            제품명·액세서리까지 조롱 확대
            │                            #이제갈아탈때 → 전환 유도
            │
            └─ 삼성 뉴질랜드 법인 (인스타그램)  ──→  '팀 쿡' 동명이인 말장난 광고
                                                      "어떤 팀 쿡을 생각하셨나요?"
```

## 읽을 거리

- **비교 광고에서 밈(meme) 마케팅으로** — 과거 삼성의 대애플 광고가 제품 스펙 비교 중심이었던 데 비해, 이번에는 동명이인·말장난·해시태그 같은 SNS 문법을 쓴다. 광고비 대신 조회수와 인용으로 확산되는 방식이다.
- **'폴더블 원조' 프레임 선점** — 애플이 폴더블 시장에 처음 진입하는 시점을 골라 "우리는 이미 오래 접어왔다"를 반복하는 것은, 카테고리 주도권을 여론에 각인시키려는 의도로 읽힌다.
- **법인별 동시 전개** — 미국(기술 우위)과 뉴질랜드(유머)가 역할을 나눠 같은 시기에 움직였다. 본사 차원의 조율된 캠페인일 가능성이 있다.

> 위 '읽을 거리'는 영상에 직접 언급된 내용이 아니라 보도 사실에 대한 해석입니다. 영상이 전한 사실만 필요하다면 [핵심 3가지](#핵심-3가지)까지만 참고하세요.

# 유튜브 영상 요약 (전사본 + 요약본)

유튜브 URL 하나를 받아 **영상 + 자막 + 전사본.md + 요약본.md** 를 한 폴더에 남긴다.
결과물 예시는 `week-4/class/` 폴더를 그대로 참고한다.

## 절차

1. **저장 폴더 결정** — 사용자가 지정하지 않으면 가장 최근 `week-*/class/` 를 쓴다. `ls -d week-*` 로 확인할 것.
2. **다운로드** — `fetch-video.sh` 실행. 출력의 `⚠ 제작자 제공 자막 없음` 경고를 놓치지 말 것.
3. **자막 정리** — `clean-subs.sh` 로 중복을 제거해 `시각<TAB>문장` 목록을 얻는다.
4. **내용 파악** — 3번 출력을 읽고 주제·등장 주체·시간 흐름을 파악한다. 오인식 후보를 따로 메모한다.
5. **전사본 작성** — `<주제>_전사본.md`
6. **요약본 작성** — `<주제>_요약.md`
7. **보고** — 두 파일 링크 + 한 줄 요약 + **오인식 교정 건수**를 알려준다. mp4를 커밋할지 물어본다(아래 [git 주의](#git-주의) 참고).

파일명의 `<주제>`는 영상 제목이 아니라 **내용을 한눈에 알 수 있는 짧은 한국어**로 정한다.
(예: 제목 `＂팀 쿡도 갤럭시로 환승＂…대형 소식 전한 삼성전자에 '깜짝'` → `삼성-애플-디스전`)

## 스크립트

```bash
# 1) 영상 + 자막 받기 (ko-orig = 원본 음성인식, en = 영어 번역)
bash .claude/skills/youtube-summary/scripts/fetch-video.sh "<URL>" week-4/class

#    자막만 필요할 때 / 해상도를 낮출 때
SKIP_VIDEO=1 bash .claude/skills/youtube-summary/scripts/fetch-video.sh "<URL>" week-4/class
MAX_HEIGHT=720 bash .claude/skills/youtube-summary/scripts/fetch-video.sh "<URL>" week-4/class

# 2) 자막 중복 제거 -> "시각<TAB>문장"
bash .claude/skills/youtube-summary/scripts/clean-subs.sh "week-4/class/<파일>.ko-orig.srt"
```

## 자동 자막의 함정 (가장 중요)

대부분의 한국 뉴스 영상에는 **제작자 자막이 없고 자동 생성 자막만 있다.** 이걸 전제로 작업한다.

- **`ko-orig` 가 원본** — 한국어 음성인식 결과. `ko`, `en` 등 나머지 180여 개 언어는 이걸 기계 번역한 2차 가공물이다. 한국어 영상이면 반드시 `ko-orig` 를 출처로 쓴다.
- **rolling 중복** — 자동 자막은 한 줄씩 밀려 올라가는 구조라 같은 문장이 2~3번 반복된다. 435줄 자막이 실제로는 43문장이다. 반드시 `clean-subs.sh` 를 거친다.
- **고유명사·숫자가 깨진다** — 실측 오인식 예:

  | 자막 원문 | 실제 | 유형 |
  |---|---|---|
  | 갤럭시 G 폴데이 | 갤럭시 Z 폴드 | 제품명 |
  | 쿡 전시효 | 쿡 CEO | 영문 약어 |
  | 팀 애플전 최고 경영자 | 팀 쿡 애플 최고경영자 | 인명 누락 |
  | 천만 해가 넘는 | 천만 회가 넘는 | 단위 |
  | 일부 개시물 | 일부 게시물 | 단순 오인식 |
  | 베겼다 | 베꼈다 | 단순 오인식 |

- **교정은 추론임을 명시한다** — 문맥으로 고친 것이지 음성을 들어 확인한 게 아니다. 교정 표를 전사본에 남기고, 요약본에는 경고 블록으로 "인용 시 원본 재확인" 을 적는다.
- **날짜·조회수·제품명은 특히 위험** — 요약본 맨 아래에 교차 확인 대상으로 따로 적어준다.
- **마지막 줄이 잘린다** — `입니다.` 처럼 끊긴 클로징은 `(YTN 지금이뉴스)입니다.` 로 보완하고 교정 표에 올린다.

## 작성 규칙

- **한국어**, 설명체(`~했습니다` / `~이다` 중 영상 톤에 맞춰 하나로 통일).
- **전사본은 원문 보존, 요약본은 교정 적용.** 전사본의 타임스탬프 표는 자막 문구를 절대 손대지 않는다. 검증용이다.
- **요약본은 위에서 아래로 읽다가 멈출 수 있게** 구성한다. 한 줄 → 핵심 3가지 → 주체별 표 → 흐름 → 해석.
- **사실과 해석을 섞지 않는다.** 영상에 없는 내용은 '읽을 거리' 섹션에만 넣고 `[!NOTE]` 로 구분한다.
- 표를 적극 쓴다. 주체가 둘 이상이면 주체별 표로 쪼갠다.
- 추측에 `~할 것이다` 같은 단정을 쓰지 않는다. `~로 읽힌다`, `~가능성이 있다`.

## 알려진 함정

이번 작업에서 실제로 막힌 지점들이다. 같은 실수를 반복하지 말 것.

| 증상 | 원인 / 대응 |
|---|---|
| `yt-dlp: command not found` | winget이 패키지 폴더를 사용자 PATH에 직접 추가한다. 설치 직후 셸에는 미반영. `fetch-video.sh` 가 PATH를 자동 보정하므로 스크립트를 쓸 것. |
| `HTTP Error 429: Too Many Requests` | 자막 여러 언어를 연속 요청하면 발생. `--sleep-subtitles 3` 필수. 한 언어가 실패하면 `--convert-subs` 후처리도 건너뛰어진다. |
| 콘솔에 한글이 `����` | PowerShell 출력 코드페이지 문제. **파일은 정상이다.** 확인이 필요하면 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` 를 먼저 실행. |
| `Test-Path` 가 있는 파일을 False 로 | 파일명의 `[...]` 를 PowerShell이 와일드카드로 해석. `-LiteralPath` 를 쓸 것. |
| 파일명에 `＂`, `⧸` 같은 이상한 문자 | Windows 금지문자 `"`, `/` 를 yt-dlp가 비슷한 유니코드로 치환한 것. 정상이다. ASCII가 필요하면 `--restrict-filenames`. |
| `sed` 로 마크다운 표 수정 실패 | 표의 `|` 가 sed 구분자와 충돌. 표 수정은 Edit 툴을 쓸 것. |
| Python 이 있는데 `pip` 가 없다 | Microsoft Store 스텁이다. Python 경로(`pip install yt-dlp`)는 쓰지 말고 winget 독립 실행본을 쓴다. |

## git 주의

영상 파일은 용량이 크고 저장소 이력에 영구히 남는다. 이 프로젝트 `.gitignore` 에는 **영상 확장자 규칙이 없다.**

- 작업을 마치면 **mp4를 커밋할지 사용자에게 물어본다.** 임의로 커밋하지 않는다.
- 권장안: `.gitignore` 에 `*.mp4` 를 추가하고 문서·자막(`.md`, `.srt`)만 커밋한다. 전사본에 재현 명령이 있으므로 영상은 언제든 다시 받을 수 있다.
- 44 MB 를 넘는 파일은 GitHub 경고 대상(50 MB)에 가깝다는 점을 알려준다.
